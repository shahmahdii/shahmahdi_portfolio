# Mahdi Hasan — Research Portfolio

A responsive, single-page academic/research portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to GitHub Pages
1. Create a GitHub repository (for example `portfolio`).
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save. GitHub will publish the site.

## Customize
- Replace the hero visual in `index.html` if you want a profile photo.
- Add project demo/GitHub links to the project cards.
- Add a `cv.pdf` file and connect a Resume button if desired.
- Update the footer year when appropriate.

Content is based on the supplied CV and intentionally does not claim publications are already published; the CV describes the manuscripts as in preparation.

## Included assets
- `cv.pdf` — your supplied CV, linked from the Download CV buttons.
- `medical-ai.svg` — custom abstract medical-imaging/neural-network hero artwork.

## Profile photo
The design intentionally leaves the hero visual as research artwork. If you add a professional headshot later, it can be placed beside the hero artwork without changing the layout.
